# Python Control Structures

A beginner-friendly Jupyter Notebook containing 50 practice exercises on Python conditional logic and basic decision-making.

## Contents

The notebook demonstrates:

- `if`, `elif`, and `else` statements
- ` for loop ` problems
- problems on `nested loops` and `nested conditions`
- Comparison operators and chained comparisons
- Logical operators: `and`, `or`, and `not`
- Arithmetic and modulo checks
- Positive, negative, zero, even, and odd classification
- Finding greater, smaller, largest, smallest, and middle values
- Divisibility and range checks
- Marks, grades, voting eligibility, salary, bonus, and discount conditions
- Nested conditions
- Leap-year validation
- Temperature classification
- Electricity-bill calculation
- Triangle validation

## Requirements

- Python 3
- Jupyter Notebook or JupyterLab
- VS Code with the Jupyter extension, if using VS Code

The notebook uses only Python's built-in features and does not require any third-party packages.

## Running the Notebook

1. Open `python(control_structures).ipynb` in Jupyter Notebook, JupyterLab, or VS Code.
2. Select a Python 3 kernel.
3. Run the cells from top to bottom.
4. Enter values when prompted by each exercise.

To start Jupyter Notebook from this directory:

```bash
jupyter notebook
```

## Learning Path

The exercises progress from simple single-condition checks to more involved combinations of conditions:

1. Basic number and comparison checks
2. Divisibility, ranges, and number classification
3. Marks, age, salary, and purchase conditions
4. Multiple values and compound logical expressions
5. Nested conditions and multi-case problems
6. Practical examples such as leap years, bills, and triangle validation

## Notes

- Each code cell is independent and generally asks for input using `input()`.
- Run a cell again whenever you want to try a different value.
- The notebook is intended for practice, so compare the condition in each prompt with the corresponding Python expression.
